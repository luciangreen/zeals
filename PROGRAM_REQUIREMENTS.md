# ZEALS Program Requirements

This repository implements the staged ZEALS requirements in SWI-Prolog:

1. Problem/case/perturbation declarations and validation.
2. Registry-backed deterministic state.
3. Perturbation-dimension generation with compatibility and limits.
4. Guarded execution with structured result and trace events.
5. Verification separation and candidate resolution.
6. Behaviour profiling and conservative capability inference.
7. Failure-boundary detection from contrasting outcomes.
8. Component extraction and dependency graph utilities.
9. Synthesis-plan generation with explicit unresolved fallback.
10. Generated expert module emission and synthesis reporting.
11. CLI commands and interactive predicates.
12. Unit and integration tests.

The full detailed source specification is preserved in `pr1.txt`.
